## Installation

Clone the [repository](https://github.com/durrantlab/promit_search):

```bash
git clone git@github.com:durrantlab/promit_search.git
```

Install `promit_search` using `pip` after moving into the directory.

```sh
pip install .
```

This will install all dependencies and `promit_search` into your current Python environment.

## Development

We use [pixi](https://pixi.sh/latest/) to manage Python environments and simplify the developer workflow.
Once you have [pixi](https://pixi.sh/latest/) installed, move into `promit_search` directory (e.g., `cd promit_search`) and install the environment using the command

```bash
pixi install
```

Now you can activate the new virtual environment using

```sh
pixi shell
```
